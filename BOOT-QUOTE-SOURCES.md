# SNAP FE boot quote sources

The 1.2.4 boot screen deliberately uses a small set of self-contained lines
from landmark industry presentations. The event is shown with every quote so
the wording never appears without context.

- Satoru Iwata, *Heart of a Gamer*, GDC 2005:
  https://www.gdcvault.com/play/1014847/Heart-of-a
- Satoru Iwata, *Disrupting Development*, GDC 2006 (official Nintendo
  transcript republished with source attribution):
  https://www.nintendoworldreport.com/news/11223/iwatas-2006-gdc-keynote-address
- Reggie Fils-Aime, Nintendo E3 2004 press conference recording:
  https://www.dailymotion.com/video/xa3a6ke
- Steve Race, PlayStation price announcement, E3 1995; preserved by the Video
  Game History Foundation:
  https://library.gamehistory.org/agents/corporate_entities/34
