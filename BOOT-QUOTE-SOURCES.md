# SNAP FE boot quote sources

The 1.2.9 collection has 25 short quotations. [boot_quotes.h](boot_quotes.h)
is the complete source register: each entry contains the exact text, speaker,
editorial context and source URL. Context is shown separately from the quote.

The collection covers landmark presentations and memorable development stories:
Tetris and Game Boy, PlayStation's price reveal, Yoshi's animation, Navi's birth,
Iwata's Balloon Trip programming, Captain Falcon, and the Mario jump sound.
Nintendo interviews use the publisher's English translation, not a new machine
translation. No independent source contributes more than 25 quoted words.
Whitespace and quotation punctuation may be normalized for display. Reggie's
E3 introduction retains mild profanity as spoken. No unsourced YouTuber
catchphrases are attributed to anyone.

A persistent shuffled deck runs through the collection before repeating.
Restarting the frontend or opening the lid does not consume another quote.
Corrupt or incompatible deck data is rebuilt safely. The citations below
document the original presentation sources; the header adds the complete
Nintendo interview and TIME direct-interview references.
