SNAP OS SOUND FOLDER
=====================

Place your own WAV files in this folder. WAV is the supported format.

UI button / navigation sound:
  ui_click.wav

Boot sounds selected in Settings > Sound:
  boot_chime.wav       (Default)
  boot_chime_2.wav     (Boot 2)
  boot_chime_3.wav     (Boot 3)

Theme tracks selected in Settings > Sound:
  theme_music_1.wav    (Theme 1)
  theme_music_2.wav    (Theme 2)
  theme_music_3.wav    (Theme 3)

There are intentionally no generated UI or theme sounds. A missing file
simply means that sound is silent.
