# Snap FE Alpha 1.2.1

This update improves library clarity, Home customization, ROM-folder control,
and Settings behavior while retaining the 1.2.0 launch and brightness fixes.

## Changes

- Stronger selected-game outlines and a clean `NO ART` placeholder for games
  without scraped artwork.
- New Recently Played widget, plus live R1/R2 cycling for the two Home widget
  positions with duplicate/conflicting widgets skipped automatically.
- Up to three selectable ROM folders, rescanning from the folder manager, and a
  ROM-folder step during initial setup.
- Select now opens per-system settings.
- Programmable SNAP-only Menu double-tap and triple-tap app actions.
- Improved Device naming/alignment.
- All collapsible Settings groups reset closed after leaving Settings.
- Hotkey edits now prompt to Save, Discard, or Cancel instead of saving every
  adjustment immediately.

## Updating

Download `SnapFE-Alpha-1.2.1.zip`, extract it directly onto the Knulli `SHARE`
partition with Merge/Replace enabled, then run **Snap FE (Set As Default)** from
Ports once. Do not delete the existing `system/snapos` folder first.

The package does not contain or remove user settings, favorites, ROMs, saves,
save states, BIOS files, accounts, API keys, or scraped game artwork.
