# Snap FE Alpha 1.2.3

This visual refresh makes App Focused Home feel consistent across every color
theme while preserving the 4x2 layout, app movement, widgets, and page controls
introduced in 1.2.2.

## Changes

- Transparent app artwork now sits on a rounded tile generated from the active
  theme instead of carrying a fixed background color.
- The selected app receives a clean, tight three-pixel accent outline without
  adding a second border around the icon.
- The complete App Focused icon set has been refreshed: Consoles, Library,
  Favorites, Settings, RetroArch, Radio, Music, Mini Games, Link Play,
  Flashlight, Achievements, Calculator, and Surprise Me.
- Favorites, RetroArch, Radio, and Mini Games now use their corrected latest
  artwork rather than the older icon revision.
- Icon assets are normalized for the handheld display to keep the app pages
  responsive and visually consistent.

## Updating

Download `SnapFE-Alpha-1.2.3.zip`, extract it directly onto the Knulli `SHARE`
partition with Merge/Replace enabled, then run **Snap FE (Set As Default)** from
Ports once. Do not delete the existing `system/snapos` folder first.

The package does not contain or remove user settings, favorites, ROMs, saves,
save states, BIOS files, accounts, API keys, or scraped game artwork.
